# Landing - SaaS App Template

Clean and flexible layout built for modern SaaS products, Supports both light and dark themes for visual flexibility, Crafted with Tailwind CSS for fast customization, Straightforward hero section focused on product messaging, Purpose built sections for features, pricing and reviews, Fully responsive experience across all device sizes, Available in Next.js and React and HTML for maximum freedom.
